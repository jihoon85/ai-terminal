# Claude Terminal

Claude Code 세션 여러 개를 한 창에서 관리하는 macOS 터미널 앱입니다. 어느 세션이 내 입력을 기다리는지 한눈에 보여 줍니다.

## 기능

- **세션 상태 표시** — 작업 중, 허가 대기, 응답 완료를 사이드바 뱃지와 Dock 배지, 시스템 알림으로 알려 줍니다.
- **대화 목록** — 지난 Claude Code 대화를 날짜별·프로젝트별로 보고, 누르면 이어서 엽니다. 고정, 색 라벨, 메모를 붙일 수 있습니다.
- **검색** — 사이드바 검색창과 빠른 전환(⌘P)에서 제목, 폴더, 대화 내용으로 찾습니다.
- **화면 분할** — 여러 세션을 나란히 띄웁니다(⌘D, ⇧⌘D). 자주 쓰는 배치를 저장해 불러옵니다.
- **동시 입력** — 한 칸에 친 내용을 떠 있는 모든 칸에 함께 보냅니다(⌥⌘I).
- **종료 후 복원** — 앱을 다시 켜면 열려 있던 세션과 분할 배치가 되살아납니다.
- **업데이트** — 새 버전이 나오면 사이드바 아래에 안내가 뜨고, 앱 안에서 바로 설치합니다.

## 요구 사항

- macOS 14 이상, Apple Silicon Mac
- [Claude Code](https://claude.com/claude-code) CLI

## 설치

1. [최신 릴리스](https://github.com/jihoon85/ai-terminal/releases/latest)에서 `ClaudeTerminal-x.x.dmg`를 받습니다.
2. dmg를 열고 **Claude Terminal을 Applications 폴더로 드래그**합니다.
3. Apple 공증을 받지 않은 앱이라 첫 실행이 막힐 수 있습니다. 그때는 **시스템 설정 ▸ 개인정보 보호 및 보안**에서 "그래도 열기"를 누릅니다.
4. 처음 켜면 Claude Code 연동 여부를 묻습니다. **연동하기**를 누르면 세션 상태가 정확히 표시됩니다.

## 업데이트

앱 메뉴의 **업데이트 확인…** 또는 사이드바 아래 안내에서 설치합니다. 설치하면 앱이 다시 시작되고, Claude 세션은 이어서 열립니다.
